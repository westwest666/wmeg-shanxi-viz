# 山西省流感样病例 · 气象可视化网站

**永久网址：https://westwest666.github.io/wmeg-shanxi-viz/**（GitHub Pages，任何人可直接打开）

WMEG-Net 结题项目的交互式可视化：山西省 11 个地级市、2015–2019 年逐日数据。
地图 / 网络 / 3D 立体三种视图 + 城市独立页面 + 时间轴播放 + 温度/湿度/降水动画 + 20 天拟合输入窗口 + 模型拟合效果。

## 启动（本地）

方式一（Windows）：双击本目录下的 `启动可视化.bat`。

方式二（命令行）：

    cd "F:/大创项目/结课版本/08_可视化网站"
    python -m http.server 8788 --bind 127.0.0.1

浏览器打开 http://127.0.0.1:8788/ 。（公网版见上方永久网址，无需本地启动）

## 功能

- **全省总览（地图）**：山西省地图（11 市行政边界），按 平滑病例 / 降水量 / 气温 / 湿度 着色，可开关 19 对行政接壤边。
- **全省总览（网络）**：11 城接壤网络视图，节点大小 ∝ 平滑病例、颜色 ∝ 指标，点击进入城市页。
- **全省总览（3D 立体）**：11 个城市按行政边界挤出成立体柱，柱高 = 当前指标值、颜色 = 指标；可拖动旋转、滚轮缩放、点击城市进入；叠加降水粒子（低温转雪）、湿度雾效、气温热浪。
- **城市页**：11 市各自独立页面，含当日天气动画（雨雪/雾/气温色调，强度随降水）、前 20 天拟合输入窗口折线（原始病例柱 + 7 日平滑线）、气温/湿度/降水三联图、20 天明细表、90/120/240 天长上下文（标注训练/验证/测试集）、接壤邻居跳转。
- **模型拟合（测试集）**：总览页与城市页均展示 15 种子集成预测 vs 真实（逐日）、逐步长 RMSE（第 1–12 步）、每城 RMSE/PCC/第 1 步/第 12 步对照表；并标注持续性基线 2.1225、校准后 2.0125。
- **时间轴**：2015-01-01 ~ 2019-12-31，拖动、播放（2–20 天/秒）、输入日期、键盘 ←/→/空格；「跳到流感季」到 2019-01-15。
- **URL 参数**：`?date=2016-07-09`、`&mode=precip|tavg|rh|cases`、`&view=3d|network|map`、`&edges=0`、`&city=长治市`。

## 数据与口径

| 文件 | 内容 |
|---|---|
| `data/app_data.json` | 11 市 × 1826 天：原始病例、7 日平移平均、日均气温、相对湿度、绝对湿度、降水、距平、冷空气日 |
| `data/fit_data.json` | 测试集（2018-12-23 ~ 2019-12-31）逐日真实/集成预测、逐城逐步长 RMSE/PCC/MAE、总体指标与基线 |
| `data/geo.json` | 11 市行政区域边界（DataV GeoJSON，简化版） |

- 原始病例：`F:/大创项目/shanxi_day.xlsx`；平滑病例：03_数据/cases_smooth_2015_2019_daily_wide.csv，已核对为严格 7 日平移平均（误差 < 1e-14）。
- 气象：03_数据/wmeg_weather_cases_2015_2019_long.csv（ERA5-Land + 站点降水）；接壤边：03_数据/shanxi_adjacency.json（19 对无向边）。
- 拟合数据来自 output/fit_M5_h12_SYMADJ15（15 种子集成）；逐日预测为多窗口重叠预测按日平均，指标为测试集 132 个（城 × 步长）单元格等权口径。
- 「拟合输入窗口」= 选中日及其之前 20 天（模型 W = 20），预测目标为之后 12 步（H = 12）。

### 动画强度映射

| 当日降水 | 档位 | 城市页雨滴数 | 说明 |
|---|---|---|---|
| ≤ 0.1 mm | 0 | 0 | 无降水 |
| 0.1–2 mm | 1 | ≈ 28 | 小雨 |
| 2–5 mm | 2 | ≈ 90 | 中雨 |
| 5–10 mm | 3 | ≈ 196 | 大雨 |
| 10–25 mm | 4 | ≈ 380 | 暴雨 |
| > 25 mm | 5 | ≤ 600（封顶） | 大暴雨 |

城市页雨滴数 = clamp(降水 × 强度映射, 3, 600)；地图上每城雨滴数 = clamp(4 + √(p/25) × 66, 4, 70)；3D 视图雨滴数与柱体按城市独立叠加。

## 部署（永久公网）

本站为纯静态站点（无后端、无外部依赖），可直接部署到任意静态托管：

## 实现说明

- 零外部依赖：图表为自绘 SVG，天气动画与 3D 为 Canvas（雨滴/雪/雾/热浪粒子、柱体挤出与平面着色）。
- 3D 使用行政边界多边形挤出（高度按指标归一化）+ 手写透视投影与深度排序，支持拖动旋转、滚轮缩放、屏幕空间拾取。
- 拟合面板数据由 tools/build_fit_data.py 从 15 种子集成预测与指标文件生成；城市页/总览页随日期同步高亮。
