# 山西省流感样病例 · 气象可视化网站

WMEG-Net 结题项目的交互式可视化：山西省 11 个地级市、2015–2019 年逐日数据。
地图总览 + 城市独立页面 + 时间轴播放 + 温度/湿度/降水动画 + 20 天拟合输入窗口折线图。

## 启动

方式一（Windows）：双击本目录下的 `启动可视化.bat`。

方式二（命令行）：

    cd "F:/大创项目/结课版本/08_可视化网站"
    python -m http.server 8788 --bind 127.0.0.1

浏览器打开 http://127.0.0.1:8788/ 。

> 不能直接双击 index.html：浏览器会拦截本地 JSON 读取（file:// 跨域），必须经本地服务器。

## 功能

- **全省总览**：山西省地图（11 市行政边界），可按 平滑病例 / 降水量 / 气温 / 湿度 着色；可切换「网络视图」查看 11 城接壤网络（19 对无向边）。
- **城市页**：点击地图/网络/表格任一城市进入；显示该市当日天气动画、指标卡片、前 20 天拟合输入窗口折线（原始病例柱 + 7 日平滑线）、气温/湿度/降水三联图、20 天明细表、90/120/240 天长上下文（标注训练/验证/测试集）、接壤邻居跳转。
- **时间轴**：2015-01-01 ~ 2019-12-31，可拖动滑杆、输入日期、播放/暂停（2–20 天/秒）、键盘 ←/→/空格；「跳到流感季」一键到 2019-01-15。
- **天气动画**：
  - 降水：雨滴数量与速度随当日降水增强；气温 ≤ 0.5 °C 时转为雪；>25 °C 有热浪。
  - 湿度：相对湿度越高，雾/水汽效果越明显。
  - 气温：天空色调随气温由冷（蓝）到暖（橙）。
  - 地图上每个城市独立做动画，强度按各自当日降水。
  - 城市页底部标注动画强度档位（0–5 档）、雨滴数、雨/雪判据与雾效开关。
- **URL 参数**（便于分享/演示）：
  - `?date=2016-07-09` 指定日期
  - `&mode=precip` 指标（cases/precip/tavg/rh）
  - `&view=network` 网络视图
  - `&edges=0` 隐藏接壤边
  - `&city=长治市` 直接打开城市页

## 数据与口径

| 文件 | 内容 |
|---|---|
| `data/app_data.json` | 11 市 × 1826 天：原始病例、7 日平移平均病例、日均气温、相对湿度、绝对湿度、降水、气温/湿度/降水距平、冷空气日 |
| `data/geo.json` | 11 市行政区域边界（DataV GeoJSON，简化版） |

- 原始病例来自 F:/大创项目/shanxi_day.xlsx；平滑病例来自 03_数据/cases_smooth_2015_2019_daily_wide.csv，二者已核对为严格的 7 日平移平均（误差 < 1e-14）。
- 气象来自 03_数据/wmeg_weather_cases_2015_2019_long.csv（ERA5-Land + 站点降水）。
- 城际接壤边来自 03_数据/shanxi_adjacency.json（19 对无向边）。
- 「拟合输入窗口」= 选中日及其之前 20 天（模型 W = 20），预测目标为选中日之后的 12 步（H = 12）。

### 动画强度映射

| 当日降水 | 档位 | 城市页雨滴数 | 说明 |
|---|---|---|---|
| ≤ 0.1 mm | 0 | 0 | 无降水 |
| 0.1–2 mm | 1 | ≈ 28 | 小雨 |
| 2–5 mm | 2 | ≈ 90 | 中雨 |
| 5–10 mm | 3 | ≈ 196 | 大雨 |
| 10–25 mm | 4 | ≈ 380 | 暴雨 |
| > 25 mm | 5 | ≤ 600（封顶） | 大暴雨 |

城市页雨滴数 = clamp(降水 × 强度映射, 3, 600)；地图上每城雨滴数 = clamp(4 + √(p/25) × 66, 4, 70)。

## 实现说明

- 纯静态、零外部依赖（无 CDN、无框架），断网可用；图表为自绘 SVG，天气动画为 Canvas 粒子。
- 地图使用 GeoJSON 边界 + 等距投影；天气动画按城市多边形裁剪，因此粒子只出现在对应行政区内。
- 时间轴播放时每步重绘当前页的图表与动画；20 天窗口与训练/验证/测试划分直接取自项目设置。
