# 山西省流感样病例 · 气象可视化网站

**永久网址：https://westwest666.github.io/wmeg-shanxi-viz/**

WMEG-Net 结题项目的交互式可视化：山西省 11 个地级市、2015–2019 年逐日数据。

## CENI 风格大屏（2026-10-20）

首页 `index.html` 改为固定 16:9 的 CENI 风格省级预测大屏：深蓝 HUD、左侧实时概况/11 城排行/气象背景、中央山西地图与城际传播图、右侧模型预测/逐城误差/态势研判、底部时间轴与播放。原 v2「故事 + 过程」首页保留为 `explore.html`，功能与 URL 参数不变。

- 大屏入口：`index.html`（默认打开峰值日 2019-12-28）
- 交互：日期播放/前后一天、日期选择、病例/降水/气温切换、城市详情抽屉、逐步长 RMSE 选择、URL 深链、全屏、帮助说明、CSV 导出、键盘快捷键
- 详细探查：`explore.html`（原 v2 首页，支持 `?date=`、`&mode=`、`&city=` 等参数）
- 预览图：`preview/10_ceni大屏.png`

## v2 改版要点（2026-10-18）

- **首屏先讲结论**：2015→2019 年内峰值扩大 4.2 倍，2019-12-28 达 166.9 例；默认打开就是峰值日。
- **地图双通道**：填色默认「每十万人发病率」（人口标准化），另可切「原始病例 / 7 日变化 / 降水 / 气温 / 湿度」；圆环脉冲表示 7 日变化（红升蓝降）；19 条接壤边有模型结构底纹 + 数据滞后方向的传播粒子（标注非因果）。
- **11 城 × 5 年时间带**：按 2018–19 季峰值日期排序（最早在上），竖线=当前日期，一眼看出谁先到峰；行尾给当前值、7 日变化、发病率、峰值日。
- **播放重做**：不再每帧重建整页，整数日才更新地图/时间带/文案，图表只在日期变化时重绘；颜色过渡已移除。
- **城市页**：原有 20 天拟合输入窗口、气象三联图、表格保留；新增「模型与邻城」面板——15 种子预测扇形（P10–P90 + 中位 + 真实）、本城 vs 邻城均值 vs 全省均值、β(t) 曲线。
- **口径写清**：原始 RMSE 2.1611（比持续性差 1.8%）、校准后 2.0125（比持续性好 5.2%）、持续性 2.1225、PCC 0.8143，并在页面标注测试集口径。

## VIBE 版（`vibe.html`）

2:30、1920×1080、30fps；无旁白、双语短字幕、77 BPM 氛围 BGM，按「VIBE 知识大赏」风格重做：公式→一个数→矩阵→权重→GELU→编码器→学习前后→诚实结论→引用。视频：video/wmeg_vibe_2min30_v2.mp4（We Never 风格原创变奏 BGM；公式 token 变形、矩阵行→向量→点积→GELU 连续 morph），字幕：video/wmeg_vibe_2min30_v2.srt。

## 数据与学习过程动画（`explain.html`）

5 分钟、7 章的讲解动画：一个真实样本（太原，输入 2019-11-27 ~ 12-16，预测 12-17 ~ 12-28）从**原始逐日计数 → 7 日平移平均 → 气象去季节/标准化 → 滑动窗口与一个 batch → 多尺度因果卷积与城际图 → 时间投影/双头 → 训练损失 → 预测/评估/校准**。

- 数据全部来自真实产物：`data/explain_data.json`（样本输入张量、15 种子预测、β、原始/平滑/气象序列、训练损失曲线）；
- 页面可播放/暂停/拖进度/按章节跳转（空格、←/→），支持 `?t=秒` 深链；
- **视频版**：video/wmeg_explainer_4min30.mp4（1600×1000、10fps、4:30、内嵌中文字幕 + 背景配乐），字幕文件 video/wmeg_explainer_4min30.srt；
- 入口：主页右上角「数据与学习动画 →」。

## 启动（本地）

双击 `启动可视化.bat`，或在命令行：

    cd "F:/大创项目/结课版本/08_可视化网站"
    python -m http.server 8788 --bind 127.0.0.1

浏览器打开 http://127.0.0.1:8788/ 。公网地址见上。

## URL 参数

- `?date=2016-07-09` 指定日期；默认 2019-12-28（峰值日）
- `&mode=rate|cases|growth|precip|tavg|rh` 指标
- `&view=map|network|3d` 视图
- `&city=长治市` 直接打开城市页
- `&play=1` 自动播放

## 数据文件

| 文件 | 内容 |
|---|---|
| `data/app_data.json` | 11 市 × 1826 天：原始病例、7 日平滑、气温/湿度/降水、距平、冷空气 |
| `data/viz_extra.json` | 人口（2015–2019）、每十万人发病率、峰值统计、2018–19 季各城峰值日与排序、色阶分位数 |
| `data/mech_data.json` | 模型机理：β(t)、接触矩阵 C 的 19 条边权重、15 种子预测分位、逐日集成预测/真值、滞后相关 |
| `data/fit_data.json` | 测试集逐日真实/集成预测、逐城逐步长指标 |
| `data/geo.json` | 11 市行政边界 |

- 原始病例：F:/大创项目/shanxi_day.xlsx；平滑病例：03_数据/cases_smooth_2015_2019_daily_wide.csv（已核对为严格 7 日平移平均）。
- 人口：03_数据/shanxi_yearly_population_params_2015_2023.xlsx。
- 机理数据由 tools/extract_mech.py 从 15 个断点抽取（需 GPU 与 torch 环境，不需要重训）。
