proto3d_v2 · 验收说明

本原型验证推荐路线 B：three.js 时空立方体（对照方案 C 的疫情山脊见右下角小图）。

两种打开方式

  • 直接双击打开：可运行；因浏览器禁止 file:// 读取 JSON，使用内置周采样演示数据（262 点/城），页面顶部有橙色提示。
  • 本地服务器（完整逐日 1826 天 + 城际流量）：在 08_可视化网站 目录运行 python -m http.server 8788，访问 http://127.0.0.1:8788/design/proto3d_v2.html。

交互

  • 拖动旋转（惯性）/ 滚轮缩放 / 双指缩放；双击或 R 复位；空格 播放暂停；←→ 单步；Esc 取消选中。
  • 点击城市柱：相机聚焦该城市；点击空白/复位返回。悬停显示当日明细。
  • 底部时间滑杆、年份按钮、全省峰值按钮；右下角山脊小图点击可跳转日期，与主视图联动。

验收检查点

  • ① 真光照：柱体明暗随法线变化，地面有方向一致的投影，且有深度雾。
  • ② 轨迹：11 根发光时间管从 2015 长到 2019，管径=病例、管色=增长率；切面以上为半透明"未来"。
  • ③ 过程：播放时水平切面上升、城市环与标签同步上移，当前值实时更新。
  • ④ 传播：切面上的 19 条弧线与流动粒子沿 lead-lag 方向移动（完整数据模式下强度取 flowDaily）。
  • ⑤ 标签：11 个城市标签随切面移动、悬停高亮；6 个年份标签标出时间刻度。
  • ⑥ 性能：右下角状态（fps / 三角形数 / draw call）可读；桌面独显 ≥55 fps。
